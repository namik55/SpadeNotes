# SpadeNotes

A calm, focused and SIMPLE note-taking app for students.

**Free · Open Source · Local-first**

## Download

- [Windows (.exe)](https://github.com/namik55/SpadeNotes/releases/download/v0.1/SpadeNotes.exe)
- [macOS (.dmg)](https://github.com/namikk55/SpadeNotes/releases)

## Run from source

```bash
npm install
npm run dev
```

## Build

```bash
npm run dist        # Windows
npm run dist-mac    # macOS (requires Mac)
```

## Tech
Electron · React · Tiptap
